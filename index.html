Case StudySTREXYL

Short-term-rental professionals were finding partners in Facebook groups, spreadsheets, and cold DMs. STREXYL gives operators, co-hosts, investors, and realtors one place to find each other, negotiate, and close deals. I'm the lead engineer, building it at Coding Pixel since June 2026.

NestJSPostgreSQLTypeORMNext.jsReact + ViteSocket.ioRedisStripeClaude APIMapboxDockerAWS EC2
01

Real-time deal rooms

Chat with structured proposals that can be accepted, declined, or countered. An accepted proposal turns the chat into a deal room with the agreed terms pinned. Socket.io runs on a Redis adapter so it works across servers.

02

Keeping deals on the platform

Phone numbers, emails, and social handles are hidden in messages until a proposal is accepted. Search indexes, notification previews, and AI answers are all built from the masked text, so nothing leaks.

03

Trust and payments

Every member verifies their ID with Stripe Identity before using the marketplace, with an admin review when the automatic check fails. Stripe handles memberships, listing fees, and boosts.

04

Claude-powered concierge

An AI assistant that uses tool calling over live listings, members, and platform settings to answer questions, guide onboarding, and help members write better listings. AI also helps moderate flagged content.

05

Search-friendly public pages

Public listing and category pages built from live data so Google can find them, while staying private: first name and last initial only, price ranges, and no street addresses or contact details.

06

Quality bar

Live checks call the real API over HTTP and assert the database row, not just that a function ran. New tests are mutation-checked, and every migration is run up, down, and up again before it ships.

How I BuildWith AI

I use Claude Code every day to move faster, and I review every change it makes. AI speeds up the work; it doesn't replace judgment.

01

Plan, then build in small steps

Claude Code reads the codebase and drafts a plan first. Each step is then built, tested, and verified before the next one starts.

02

Subagents and skills

Parallel subagents handle research and independent code review. Reusable project skills (create a feature, add a database entity, deploy) keep every change following the same conventions.

03

MCP servers and hooks

MCP servers connect Claude to GitHub, a real browser for testing pages, and up-to-date library docs. Hooks run checks automatically at the right moments.

04

Project memory

Each project keeps a CLAUDE.md with its stack, structure, and lasting rules learned from real bugs, so the same mistake isn't made twice.
